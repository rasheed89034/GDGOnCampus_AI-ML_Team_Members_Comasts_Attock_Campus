# AI/ML Team — Yearly Activity Plan (2026)

Central repository for the GDG AI/ML team's 12-month learning and delivery roadmap — from foundations through NLP & LLMs, Generative AI & Agents, MLOps, capstone projects, and a year-end team startup launch.

## How this repo works

- Each month has its own folder (`month-01-...` through `month-12-...`) matching the Activity Plan.
- Every member submits their monthly hands-on challenge and article links inside their own folder: `month-XX-.../members/<your-github-username>/`.
- Work flows in through **forks and Pull Requests**, so the main repo stays the single source of truth for the whole team's progress.

## Quick start for team members

1. **Fork this repo** — click "Fork" at the top right of this page. This creates your own linked copy.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/<your-username>/GDGOnCampus_AI-ML_Team_Members_Comasts_Attock_Campus.git
   cd aiml-activity-plan-2026
   ```
3. **Create a branch for your task**:
   ```bash
   git checkout -b month-01-onboarding-foundations/your-name
   ```
4. **Add your work** inside `month-01-onboarding-foundations/members/your-name/` (code, notebooks, article links — see that month's README).
5. **Commit and push to your fork**:
   ```bash
   git add .
   git commit -m "Month 1: onboarding task - your-name"
   git push origin month-01-onboarding-foundations/your-name
   ```
6. **Open a Pull Request** from your fork's branch into this repo's `main` branch. Fill in the PR template. Tag the team lead for review.
7. Once merged, your work is permanently part of the central repo — repeat each month.
