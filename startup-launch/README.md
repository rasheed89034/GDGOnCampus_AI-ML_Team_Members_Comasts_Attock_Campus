# Year-End Milestone: Startup Launch

Runs alongside Month 12. The team channels the full year's work — data handling, ML, the NLP/LLM and GenAI tracks, MLOps — into one real, deployed product.

## Phases
- `ideation/` — problem statements, voting results, selected idea
- `build/` — data pipeline, model, and deployed product
- `validate/` — feedback notes from mentors/early users
- `launch-pitch/` — demo materials, pitch deck, launch notes
- `recognition/` — certificates / award records for the founding team

Create these subfolders as the milestone progresses.
