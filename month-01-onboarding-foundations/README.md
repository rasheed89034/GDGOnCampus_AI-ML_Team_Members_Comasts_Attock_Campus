# Month 1 — Onboarding & Foundations

Brief description of this months focus, workshop topics, and the hands-on challenge go here (see the main Activity Plan doc).

## How to submit your work

1. Fork the main repo (top-right "Fork" button) skip if you already forked it for a previous month.
2. Clone your fork and create a branch: git checkout -b month-01-onboarding-foundations/your-name
3. Add your work inside: month-01-onboarding-foundations/members/your-name/
4. Push to your fork: git push origin month-01-onboarding-foundations/your-name
5. Open a Pull Request from your fork into this repos main branch.
6. Use the PR template checklist and tag your team lead for review.

## members/
Each contributors folder should be named after their GitHub username, e.g. members/johndoe/.
